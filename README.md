# STM32 自动循迹避障小车

基于 STM32 开发的自动循迹与避障小车项目，主要实现红外循迹、超声波测距避障、舵机控制以及 PWM 电机调速等功能。

本项目最初用于学习 STM32 嵌入式开发，目前正在对早期代码进行重新设计、优化与调试，并计划进一步引入 RTOS，对整体软件架构进行改进。

> 🚧 **项目状态：持续开发与调试中**

---

## 📖 项目简介

本项目始于 **2025 年 11 月**。

最初通过 Bilibili 等平台的视频教程学习 STM32 嵌入式开发，并在学习过程中完成了小车的基础硬件搭建和软件框架，实现了电机驱动、红外循迹、超声波测距、舵机控制等基本功能。

在完成基础版本后，我发现早期代码在模块划分、任务组织、控制逻辑以及可维护性方面仍存在较大的改进空间。

因此，从 **2026 年 7 月**开始，我重新整理该项目，在理解原有代码和硬件工作原理的基础上，对程序结构和控制逻辑进行优化，并逐步将早期以“实现功能”为主要目标的代码调整为更加清晰、模块化的结构。

目前项目仍处于调试和优化阶段。

---

## 🛠️ 主要功能

目前项目包含以下功能：

- 红外传感器循迹
- 超声波测距
- 自动避障
- 舵机控制
- PWM 电机调速
- 左右电机差速控制
- OLED 信息显示
- 串口调试
- 按键及 LED 控制
- 多模块协同控制

部分功能仍在持续测试和优化中。

---

## 📁 软件结构

目前程序按照功能进行了模块化划分，主要包括：

```text
Hardware/
├── CarGo.c / .h          # 小车运动控制
├── CarTasks.c            # 小车任务及控制逻辑
├── Motor.c / .h          # 电机驱动
├── PWM.c / .h            # PWM 控制
├── Track_Init.c / .h     # 循迹模块初始化
├── TrackTask.c / .h      # 循迹控制逻辑
├── Ultrasonic.c / .h     # 超声波测距
├── Servo_PWM.c / .h      # 舵机 PWM 驱动
├── ServoTask.c / .h      # 舵机相关任务
├── Serial.c / .h         # 串口通信
├── OLED.c / .h           # OLED 驱动
├── Key.c / .h            # 按键
└── LED.c / .h            # LED
```

随着项目继续优化，该目录结构可能发生调整。

## 🔧 项目开发过程

### 2025.11 — 初始版本

通过视频教程学习 STM32 的基础开发流程，并完成小车基本框架搭建。

这一阶段主要目标是理解并实现：

- 电机驱动

该阶段部分代码和设计思路参考了学习过程中使用的教程及相关资料。

### 2026.07 — 项目重构与优化

重新开始整理早期项目。

在能够理解原有程序运行逻辑的基础上，对程序进行进一步修改和优化，主要关注：

- 改善代码结构
- 拆分不同功能模块
- 优化循迹控制逻辑
- 优化避障流程
- 改善不同模块之间的协作
- 减少不必要的阻塞式控制
- 提高代码可读性和可维护性
- 重新进行实际硬件测试与参数调整

当前重点是进一步提高循迹与避障过程的稳定性，同时继续整理早期代码中不合理的结构。

因此，本仓库中的部分实现仍可能随着测试结果发生较大变化。

## 🚀 下一步计划

下一阶段计划尝试将 **RTOS** 引入项目。

目前程序中的循迹、超声波检测、舵机控制、电机控制以及显示等功能之间存在多个需要协调执行的任务。

后续计划通过 RTOS 进一步学习和实践：

- Task / Thread 任务划分
- 任务优先级
- 软件定时
- 消息队列
- 信号量 / 互斥量
- 不同任务之间的数据通信
- 实时任务调度

计划在保证现有裸机版本基本稳定的基础上，再逐步进行 RTOS 版本的设计与迁移。
